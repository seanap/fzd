# FZD v2.0.0 — Find your way.

Explore unfamiliar Linux directories, remember the useful places, and get back
to work. FZD 2.0 integrates upstream zoxide, adds native shell completion and
optional gray inline suggestions, and introduces a clearer product README.

## What's new

- **`lf` explores.** Open the familiar directory explorer with previews.
- **`lf immich` remembers.** Jump directly to zoxide's highest-ranked match.
  Partial names (`lf imm`) and multiple terms (`lf docker immich`) work too.
  When there is no learned match, FZD opens discovery with your query ready.
- **`lff immich` finds.** Open global search prepopulated with a query; `lff`
  starts ready for input. FZD remains the discovery interface.
- **Learn as you navigate.** FZD visits and ordinary shell navigation feed the
  existing zoxide database, respecting upstream configuration and `z`/`zi`.
- **Shell completion and optional inline suggestions.** Native Bash/zsh Tab
  completion uses learned directories. The explicit `--inline-suggestions`
  installer option configures upstream ble.sh or zsh-autosuggestions; press
  Right to accept gray text. Enter still resolves a partial query immediately.
- **Consistent preview colors.** Tree and eza directory previews apply the
  configured directory and regular-file colors used by the main list.
- **A redesigned README.** A concise introduction, a simple installation path,
  the original banner/GIF, and detailed documentation in `docs/TECHNICAL.md`.

## Install

For source installation with inline suggestions, run as your normal user:

```bash
git clone --branch v2.0.0 https://github.com/seanap/fzd.git
cd fzd
bash install.sh --deps recommended --inline-suggestions
```

Open a new terminal and try `lf`. Omit `--inline-suggestions` to leave suggestion
engine setup unchanged; `--shell bash` or `--shell zsh` targets one shell.
Missing system dependencies are installed through your distribution's package
manager. FZD itself installs under `~/.local`.

For Ubuntu/Debian, download the `.deb`, `SHA256SUMS` and `SOURCE`, then run:

```bash
sha256sum --ignore-missing -c SHA256SUMS
cat SOURCE
sudo apt install ./fzd-2.0.0-debian-all.deb
```

Arch users can build the checksum-pinned `PKGBUILD` with `makepkg -si`, or install
the matching prebuilt package with `sudo pacman -U ./fzd-2.0.0-1-any.pkg.tar.zst`.
AUR submission is separate; an AUR account is not needed for these downloads.
Packages leave shell startup files untouched. Add the following to your Bash/zsh
startup file for native navigation/completion, then open a new terminal:

```bash
. /usr/share/fzd/integration.sh
```

The source installer is the simplest route for configuring inline engines.
Package users can configure independently installed engines as described in the
[technical guide](https://github.com/seanap/fzd/blob/v2.0.0/docs/TECHNICAL.md).

## Upgrading from v1.6

**Zoxide >= 0.9.0 is now required.** FZD uses upstream zoxide; it ships no custom
replacement, bundled binary, or separate navigation database.

`lf name` now resolves learned matches directly, falling back to discovery.
Use `lff name` whenever you want global search. Direct directory arguments and
`lf -` still work. Existing `lf`/`lff` commands are preserved; use `fzd_cd` and
`fzd_find` if those names are already taken. Shell customizations, existing
completion handlers and zoxide hooks are retained where already configured.

Source users can update their checkout and rerun the installer. Package users
upgrade through APT/pacman. Before switching from a source installation to a
package, uninstall the user-local copy to avoid shadowing `/usr/bin/fzd`.
Uninstall retains user configuration, navigation history and shared engines.

## Validation and provenance

Validation covers Linux x86_64 Ubuntu 24.04, Debian 13 and current Arch Linux,
plus Fedora 44 staged-runtime compatibility. Both fzf 0.44.1 and 0.65.2 are
tested with real terminal sessions and upstream suggestion engines. Repeated
source, Debian and Arch builds are checked for byte reproducibility.

ARM64 and Fedora RPM packaging remain outside this release's validation scope.
Use the custom `fzd-2.0.0.tar.gz` for checksum verification and recipe builds;
GitHub's automatically generated source archives are different files.
`SOURCE` records the immutable Git commit and timestamp. `SHA256SUMS` verifies
asset integrity; it is not an independent cryptographic signature.
