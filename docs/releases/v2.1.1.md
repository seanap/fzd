# FZD v2.1.1 — Easier first installation

Simple and Enhanced now install missing plocate tools without requiring
`--allow-package-indexing`. If the default search index is unavailable after
package setup, the installer runs `updatedb` using the existing system settings.

## What changed

- Plain `bash install.sh` and `bash install.sh --enhanced` install plocate through
  the native package manager and initialize its default index when needed.
- Existing populated indexes are reused. FZD leaves indexing exclusions,
  `/etc/updatedb.conf`, timers and services unchanged; native package setup
  retains its distribution behavior.
- `--no-updatedb` skips installer-triggered initialization. `--deps none` also
  skips it, and custom `FZD_LOCATE_DBS` databases are never initialized or rewritten.
- Missing sudo authorization, unavailable indexing tools or indexing failures
  produce guidance and preserve a usable installation with filesystem search
  fallback. Runtime searches never invoke `updatedb`.
- The old `--allow-package-indexing` flag remains accepted for compatibility.

## Install or upgrade

Run as your normal user, with root or cached sudo authorization (`sudo -v`) for
system package installation and index initialization:

```bash
git clone --branch v2.1.1 https://github.com/seanap/fzd.git
cd fzd
bash install.sh --enhanced
```

Use plain `bash install.sh` for Simple. For an existing source installation,
rerun the installer with your existing prefix and shell options. Open a new
terminal afterward. Initial indexing can take time on large filesystems.

Ubuntu/Debian users can download `fzd-2.1.1-debian-all.deb`, `SHA256SUMS` and
`SOURCE` from this release:

```bash
sha256sum --ignore-missing -c SHA256SUMS
cat SOURCE
sudo apt install ./fzd-2.1.1-debian-all.deb
```

Arch users can build the checksum-pinned `PKGBUILD` with `makepkg -si`.
Packages leave user startup files untouched and use native dependency setup;
the source-installer initialization step does not run during package staging.
See [installation and indexing guidance](../TECHNICAL.md#plocate-readiness-and-package-indexing).

## Validation

The installer change passed 114 focused dependency, installation, upgrade,
rollback and packaging tests without skips, plus static checks. Publication
requires both complete fzf regression configurations, deterministic builds and
Ubuntu, Debian, Arch and Fedora userspace checks on the final release commit.
Fedora coverage remains staged runtime compatibility rather than an RPM lifecycle
test. Native desktop appearance and clipboard/font integration retain the manual
validation limits described in the v2.1.0 notes.
