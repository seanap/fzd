# FZD v0.1.0-rc.2

This is a **prerelease for testing**, not a stable release.

FZD is a fast, keyboard-first Bash file explorer built around fzf, with fuzzy
navigation, previews, directory history and safe single-item file operations.

This candidate corrects GitHub release-asset naming. The Debian download is
`fzd-0.1.0-rc.2-debian-all.deb`; its internal version remains `0.1.0~rc.2-1`,
which sorts before stable `0.1.0`. Builders produce the final filename and
matching checksums automatically. Application behavior, keyboard controls,
previews, branding and shell integration are unchanged from rc.1.
The public rc.1 tag is preserved; its draft release remains unpublished.

## Install

Linux x86_64 validation covers Ubuntu 24.04, Debian 13 and current Arch Linux.
Fedora 44 has staged-runtime validation, not an RPM package. ARM64, native desktop
terminal behavior, SELinux enforcement and all removable/network-filesystem
Trash cases are not validated.

Download the Debian package, `SHA256SUMS` and `SOURCE` from this candidate's
GitHub release when published, then run:

```bash
sha256sum --ignore-missing -c SHA256SUMS
cat SOURCE
sudo apt install ./fzd-0.1.0-rc.2-debian-all.deb
```

FZD is not in the official Ubuntu/Debian repositories. Packages leave your home
and shell startup files untouched. Add this line to `~/.bashrc` or
`${ZDOTDIR:-$HOME}/.zshrc`, then open a new terminal or run it now:

```bash
. /usr/share/fzd/integration.sh
```

Run **`fzd_cd`**, or **`lf`** when that name is available. Existing `lf` commands
are preserved. Defaults work without creating a configuration file.

On fully updated Arch, download `PKGBUILD` from the release into a clean
directory and run `makepkg -si` as your normal user. Its pinned checksum verifies
the custom source archive. A prebuilt Arch package is also prepared for review.
AUR submission is separate; no AUR listing is claimed.

## Controls and lifecycle

Left/Right navigate parent/child directories; Enter returns to the shell in a
directory or opens a file in your editor. Type to filter; Ctrl+F searches globally.
Alt+Left/Right traverse history; Alt+H opens recents. Ctrl+C/X/V (or Alt+C/X/V)
copy/cut/paste. Ctrl+R/F2 renames; Ctrl+N/F7 creates a folder; F8 moves to Trash
after confirmation. F1 shows help; Esc cancels.

Trash needs `gio` (`libglib2.0-bin` on Ubuntu/Debian) or `trash-put`; there is no
permanent-delete fallback. Some terminals intercept shortcuts; use the alternatives.
Large foreground copies can block navigation. Persistent state uses cooperative
locking, not a power-loss transaction database.

Upgrade through APT or a rebuilt Arch recipe. Remove with `sudo apt remove fzd`
or `sudo apt purge fzd`; on Arch use `sudo pacman -R fzd`. User configuration,
clipboard and recent directories are retained. Remove your manually added shell
integration line after uninstalling. Uninstall a user-local source installation
before transitioning to packages, preserving preferences.

## Provenance

Use the custom `fzd-0.1.0-rc.2.tar.gz`, not GitHub's automatically generated
source links. `SOURCE` identifies the immutable Git commit and source timestamp.
`SHA256SUMS` provides integrity checking and Git provenance, not an independent
cryptographic signature. Publication requires separate approval after validation.
